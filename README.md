# HoloBrain · 双语 3D 脑图谱 / Bilingual 3D Brain Atlas

An interactive, bilingual (中文 / English) 3D brain atlas — explore cortical and
subcortical structures, slice the brain in any plane, and test yourself in
Learning Mode.

🔗 **在线工具 / Live tool: https://hughyau.com/brain**

## 功能 / Features

* 🧠 **130+ 结构的交互式 3D 图谱**（主要动脉、颅神经、脑室、脑干、间脑、端脑…）
Interactive 3D atlas with **130+ structures** (major arteries, cranial nerves, ventricles, brainstem, diencephalon, telencephalon…)
* 🔪 **矢状 / 水平 / 冠状切面**，半透明皮层揭示实心深部结构
**Sagittal / axial / coronal sections**, with a translucent cortex revealing solid deep structures
* 🌐 **全中英双语**，分级证据描述
**Fully bilingual (Chinese/English)** with graded evidence descriptions
* 🎓 **学习模式** —— “识图选名” 与 “听名找位” 两种测验
**Learning Mode** — featuring two types of quizzes: "Identify Structure by Image" and "Locate Structure by Name"
